# Adventure Works Cycle Sales Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze
Adventure Works Cycle sales performance.

The dashboard provides insights into sales, customers, orders, quantity,
products, product performance, customer performance, regional sales,
and production costs.

## 🎯 Project Objectives
- Analyze overall sales performance
- Track sales by year, month, and quarter
- Identify top-performing products
- Analyze customer-wise sales
- Compare sales across regions
- Compare Sales Amount with Production Cost
- Create interactive filters for business analysis
- Present key business KPIs in an easy-to-understand dashboard

## 🛠️ Tools & Technologies

## 🔍 Interactive Filters

The dashboard includes filters/slicers for:
- Year
- Sales Territory Region
- Product Name
These filters allow users to interactively explore different
business segments.

## 💡 Key Insights

The dashboard helps identify:
- Sales trends over different years and months
- High-performing products
- High-value customers
- Regional sales performance
- Differences between sales and production costs
- Quarterly sales contribution
